# سامانه مدیریت فروشگاه

سیستم فارسی مدیریت فروشگاه با Django + React (Vite)، شامل چک‌های پرداختی/دریافتی، بدهکار و بستانکار، سفارشات، پیشنهادات هوشمند از روی CSV فروش، و گزارش‌های مالی از جمله سود و زیان.

## پیش‌نیازها

- Python 3.12+
- Node.js 20+
- npm

## راه‌اندازی Backend (پورت ۸۰۰۲)

```bash
cd /home/mohammad/Projects/store-manager
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cd backend
python manage.py migrate
python manage.py seed_users
python manage.py seed_demo   # اختیاری: داده نمونه
python manage.py runserver 0.0.0.0:8002
```

## راه‌اندازی Frontend (پورت ۵۱۷۷)

```bash
cd /home/mohammad/Projects/store-manager/frontend
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:5177` باز کنید. درخواست‌های `/api` به بک‌اند روی پورت ۸۰۰۲ پروکسی می‌شوند.

### دسترسی‌ها (خلاصه)

- **مدیر:** همه بخش‌ها، حذف رکوردها، تأیید/لغو سفارش، مدیریت کاربران، گزارش فعالیت‌ها
- **حسابدار:** ثبت و ویرایش چک، طرف‌حساب، دفتر، کالا، سفارش، ورود CSV و مشاهده گزارش‌ها (از جمله سود و زیان) — بدون حذف و بدون مدیریت کاربران

## امکانات

1. مدیریت چک‌های پرداختی و دریافتی + تقویم سررسید
2. مدیریت بدهکار و بستانکار (طرف‌حساب + دفتر معین)
3. هزینه و درآمد + حساب‌های بانکی
4. سفارشات فروش/خرید
5. ورود CSV فروش‌های گذشته و پیشنهاد هوشمند خرید (زمان و مقدار)
6. گزارش‌های فروش، خرید، مطالبات، موجودی و سود و زیان با فیلتر تاریخ شمسی
